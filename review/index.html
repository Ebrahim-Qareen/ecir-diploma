Round 1 · The SOC and the SIEM

from Session 1

Who works in a SOC, what counts as an incident, and why a SIEM exists.

Q1 Which of these is an INCIDENT, not just an event?

  • A server rebooted after a scheduled patch
  • An attacker used stolen credentials and is inside the network
  • A backup job finished
  • A user logged in successfully at 09:00

Q2 Your company website is defaced. Which part of CIA was broken?

  • None of them
  • Confidentiality
  • Availability
  • Integrity

Q3 Why can reading one log file never replace a SIEM?

  • Log files delete themselves
  • Log files are always encrypted
  • One file is too small
  • One file cannot correlate activity across many systems

Q4 A breach is confirmed and needs forensics, legal and comms together. Who takes it?

  • The help desk
  • The IR team
  • SOC L1
  • The developer team

Q5 A SOC sees 1,000,000 events, 50 alerts and 2 incidents in a day. What does that show?

  • Filtering - rules reduce noise down to what humans can work
  • Analysts are ignoring alerts
  • There were 1,000,000 attacks
  • The SIEM is broken

Q6 Which of these is NOT a SOC responsibility?

  • Investigating suspicious activity
  • Escalating confirmed incidents
  • Writing the company's business applications
  • Monitoring alerts

Q7 A rule fired, but the activity turned out to be a normal admin task. That is a?

  • True Positive
  • True Negative
  • False Positive
  • False Negative

Q8 Why do SOCs run 24/7 instead of office hours?

  • Logs only arrive at night
  • Software licences require it
  • Analysts prefer night shifts
  • Attackers deliberately act at night and on weekends

Round 2 · Logs, the pipeline and Splunk

from Session 2

Getting logs from a machine into a SIEM you can actually search.

Q9 Which is the LAST stage of the log pipeline?

  • Analysis
  • Storage
  • Alerting
  • Parsing

Q10 Logs reach Splunk but the fields are not searchable. Which stage failed?

  • Parsing
  • Shipping
  • Collection
  • Alerting

Q11 You want ONLY the Sysmon channel forwarded. Which file do you edit?

  • server.conf
  • outputs.conf
  • inputs.conf
  • indexes.conf

Q12 The forwarder is installed but no data arrives. What do you check first?

  • The dashboard colour scheme
  • The alert severity
  • The analyst's password
  • That it can reach the indexer on 9997

Q13 index=linux returns nothing, but the agent is running. Most likely cause?

  • Linux cannot be monitored
  • inputs.conf is sending to a different index
  • The web port is wrong
  • Splunk deletes Linux logs

Q14 Why keep separate indexes for Windows, Linux and Sysmon?

  • Faster searches, and different retention and access per source
  • It reduces licence cost to zero
  • It looks tidier
  • Splunk requires exactly three

Q15 What does | stats count by src_ip | sort -count give you?

  • The newest event only
  • A single total number
  • A list of usernames
  • The noisiest source IPs, highest first

Q16 When you sit down to investigate collected logs, which pipeline stage are you in?

  • Shipping
  • Generation
  • Collection
  • Analysis

Round 3 · Telemetry and the analyst method

from Session 3

Reading events, pivoting, and naming what you found in ATT&CK terms.

Q17 Which field ties a logon to everything that session did afterwards?

  • Logon ID
  • Source Port
  • Event ID
  • Keywords

Q18 A Sysmon EID 3 has no Logon ID. How do you find who caused it?

  • It cannot be found
  • Read the firewall log
  • Search by timestamp only
  • Pivot on ProcessId to the matching EID 1

Q19 What does native 4688 typically LACK compared with Sysmon EID 1?

  • The file hash and a reliable parent process
  • The username
  • The timestamp
  • The computer name

Q20 WINWORD.EXE spawns powershell.exe. Why is that a red flag?

  • A document should not launch a shell - it suggests a malicious macro
  • It means the disk is full
  • PowerShell is malware
  • Word always spawns PowerShell

Q21 On Ubuntu, which file records SSH logins and sudo use?

  • /var/log/dmesg
  • /var/log/syslog
  • /etc/shadow
  • /var/log/auth.log

Q22 What does auditd give you that auth.log does not?

  • Encrypted storage
  • The exact commands executed, at syscall level
  • Prettier colours
  • Automatic blocking

Q23 You confirmed one infected host. What is the golden question?

  • Where did it come FROM, and where did it GO?
  • Who do we blame?
  • Can we reimage now?
  • Which antivirus failed?

Q24 certutil.exe downloads a file from the internet. Which ATT&CK technique?

  • T1105 Ingress Tool Transfer
  • T1070 Log Clearing
  • T1110 Brute Force
  • T1486 Ransomware

Q25 You see 4720 then 4732 for the same account. What happened?

  • An account was created, then added to a privileged group
  • A user changed their password
  • A service was installed
  • A log was cleared

Q26 What is the correct order of the 5-minute first response?

  • Contain, orient, document, validate, scope
  • Document, contain, orient, scope, validate
  • Orient, validate, scope, contain, document
  • Scope, document, contain, orient, validate

Round 4 · Detection, triage and threat intel

from Session 4

Writing rules, working the queue, judging indicators.

Q27 Your custom Wazuh rule never fires. What is the most likely cause?

  • The rule ID is too high
  • Alerts are disabled globally
  • Wazuh does not support custom rules
  • The if_sid parent rule never matches that log

Q28 In the Wazuh Ruleset Test, what does Phase 3 show you?

  • The agent version
  • Which rule matched the log
  • The disk usage
  • The raw timestamp

Q29 In a Sigma detection, a LIST of values means which logic?

  • NOT - exclude them
  • XOR
  • AND - all must match
  • OR - any one value matches

Q30 What does condition: selection and not filter mean in plain English?

  • Alert on everything
  • Alert on the suspicious thing, except the known-good case
  • Never alert
  • Alert only on weekends

Q31 You need several command-line flags present TOGETHER. Which modifier?

  • |all
  • |base64
  • |contains
  • |startswith

Q32 Your converted Sigma query returns nothing in the SIEM. What do you check?

  • Change the rule level
  • Delete the rule
  • Nothing - conversion is always correct
  • Escaped characters and field names, then test on real data

Q33 A critical alert and a low alert are both New. Which do you take first?

  • Whichever is newest
  • The critical one
  • The low one, it is quicker
  • Neither - wait for L2

Q34 An alert's IP belongs to a CDN range. What does that tell you?

  • Very little - thousands of good and bad sites share it
  • It is an internal asset
  • It is definitely malicious
  • It is definitely safe

Q35 A domain converts to a punycode form starting xn--. What does that mean?

  • It contains non-ASCII look-alike characters
  • It is expired
  • It uses HTTPS
  • It is a Microsoft domain

Q36 You confirmed some IOCs are malicious. Where do they go for automatic detection?

  • The decoder file
  • The Wazuh CDB lists
  • The agent log
  • The public SigmaHQ repo

Round 5 · IR lifecycle and forensic readiness

from Session 5

The process after “yes, this is real” — and protecting the evidence.

Q37 Which NIST phase does SANS split into three separate steps?

  • Preparation
  • Post-Incident
  • Containment, Eradication and Recovery
  • Detection and Analysis

Q38 A laptop is encrypting files right now. What must you NOT do first?

  • Capture a memory image
  • Disconnect it from the network
  • Open a case and take ownership
  • Power it off to stop the damage

Q39 Before restoring from backup, what must you verify?

  • That the backup is older than the intrusion
  • That it is on the same server
  • That it is the newest backup
  • That it is compressed

Q40 You removed the malware, but the attacker returns the next day. What was skipped?

  • Setting the TLP
  • Writing the chain of custody
  • Assigning an owner
  • Fixing the root cause

Q41 What is a write blocker used for?

  • Reading a drive without changing anything on it
  • Speeding up imaging
  • Encrypting the evidence
  • Deleting malware safely

Q42 Which of these disappears FIRST when a machine is powered off?

  • The registry
  • Archived backups
  • Files on disk
  • RAM contents

Q43 Who decides whether an incident is disclosed to customers or regulators?

  • The IT helpdesk
  • Legal and management
  • The SIEM
  • The L1 analyst

Q44 In TheHive, why mark an observable as 'is IOC'?

  • To raise the case severity automatically
  • So it can be correlated and shared as a real indicator
  • To hide it from the team
  • To delete it later

Q45 Which of these can SOAR NOT do for you?

  • Look up an IP's reputation
  • Make a judgement call on a brand-new attack
  • Disable a user account
  • Open a ticket automatically

Q46 When is the escalation matrix agreed?

  • After the post-incident review
  • While the incident is happening
  • During Preparation, before any incident
  • Only for critical incidents
